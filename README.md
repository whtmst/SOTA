## 📖 О проекте

**SOTA** - развитие аддона **GuildDKP** с полной обратной совместимостью. DKP хранится в публичных/офицерских заметках гильдии и может экспортироваться через RPGO_GuildProfiler.

### SOTA Master

- Управляет аукционами и очередью в рейд
- Один мастер на рейд (назначается автоматически)
- Запрос статуса: `/sota master` или клик по иконке Spiritual Guidance
- Права = права офицера, мастер только обрабатывает фоновые задачи

## 🎯 Функционал

### 1️⃣ DKP Assignment

Начисление/списание DKP через командную строку.

**Автоматическое управление оффлайн-игроками:**
Аддон самостоятельно включает отображение оффлайн-игроков в гильдии перед операциями с ДКП и возвращает настройку обратно после завершения операции. Это позволяет начислять ДКП игрокам в рейде независимо от их местоположения и статуса онлайна - после убийства босса можно сразу уйти в оффлайн или в другой инстанс, ДКП всё равно будет начислено.

### 2️⃣ Auctions

**Запуск:** `/sota <item link>` (Shift+клик по предмету)  
**Ставка:** `/sota bid <n>` или `!bid <n>` в чате

- `<n>` - сумма DKP
- `min` - минимальная ставка
- `max` - все DKP

**Режимы:**
- `/sota silent` - Команда позволяет отключить отправку подтверждений о приеме ставок в личные сообщения игрокам (по умолчанию включено). Это помогает избежать спама в чате при использовании сторонних аддонов (например, **[T-Bidder](https://github.com/whtmst/T-Bidder)**).

Управление через UI: пауза, отмена, завершение.

### 3️⃣ Raid Queue

**Вход:** `!queue <role>` в гильд-чате  
**Роли:** `tank`, `melee`, `ranged`, `healer`

**Управление (UI - иконка Prayer of Spirit):**
- ЛКМ по игроку → пригласить
- ПКМ по игроку → удалить
- ЛКМ по роли → пригласить всех

DKP начисляется игрокам вне инстанса. При DC игрок остается в очереди, но DKP не получает.

### 4️⃣ Transaction Log

**Открыть:** `/sota log` или иконка "note"

- Клик по транзакции → детали
- Клик по игроку → включить/исключить из транзакции
- Для транзакций с одним игроком: замена цели (коррекция ошибок)

## 💰 Типы DKP

### Ranged DKP
Начисление в радиусе **100 ярдов**. Игроки внутри инстанса не получат DKP, если вы раздаете его снаружи.

### Shared DKP
Делит сумму на всех в рейде. Пример: 1000 DKP / 30 игроков = 34 DKP каждому (округление вверх).

### Penalizing DKP
Штраф в DKP или процентах. Минимум **50 DKP** вычитается всегда, даже если баланс уйдет в минус.

## ⚙️ Настройки

**Открыть:** `/sota config` или иконка шестеренки

### Bidding options
- **Auction Timers:** 25 сек до закрытия, +8 сек при новой ставке
- **Enable OS bidding:** Приоритет MS/OS ставок
- **Raid Queue Zonecheck:** DKP только для игроков вне инстанса
- **Disable Dashboard:** Скрыть панель управления

### Boss DKP
Настройка DKP за боссов в инстансах (0-4000 DKP).

### Misc. DKP options
- **Store DKP in Public Notes:** Публичные заметки вместо офицерских
- **Bid rules:** 4 варианта правил повышения ставок
- **DKP String length:** Фиксированная длина для сортировки
- **Minimum penalty:** Минимальный штраф DKP

## 💻 Команды

### DKP

| Команда | Описание |
|---------|----------|
| `/sota dkp [player]` | Показать DKP игрока |
| `/sota class [class]` | Топ-10 DKP класса |
| `/sota +<n> <player>` | Добавить DKP |
| `/sota -<n> <player>` | Вычесть DKP |
| `/sota -<n>% <player>` | Вычесть % DKP |
| `/sota raid +<n>` | Добавить DKP рейду |
| `/sota raid -<n>` | Вычесть DKP у рейда |
| `/sota range +<n>` | Добавить DKP в радиусе |
| `/sota share +<n>` | Разделить DKP между рейдом |
| `/sota sharerange +<n>` | Разделить DKP в радиусе |
| `/sota decay <n>%` | Удалить % DKP у **всей** гильдии |

### Очередь

| Команда | Описание |
|---------|----------|
| `/sota queue` | Статус очереди |
| `/sota queue <role>` | Встать в очередь |
| `/sota addqueue <player> <role>` | Добавить игрока |
| `/sota leave` | Покинуть очередь |

### Аукцион

| Команда | Описание |
|---------|----------|
| `/sota <item>` | Начать аукцион |
| `/sota bid <n>` | Ставка (или `!bid <n>`) |

### Прочее

| Команда | Описание |
|---------|----------|
| `/sota config` | Настройки |
| `/sota log` | Журнал транзакций |
| `/sota version` | Версии аддона |
| `/sota master` | Назначить мастера |
| `/sota silent` | Тихий режим (вкл/выкл). Отключает подтверждения ставок в ЛС. |
| `/sota vc` | Проверка версий T-Bidder в рейде (SOTA: `/sota version` в личный чат) |
| `/sota help` | Справка |
